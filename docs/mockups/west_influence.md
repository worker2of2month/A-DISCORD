# Политическая карта влияния на Западе

Категория `ADISCORD_west_influence_category` показывает карту вместо боковой
иллюстрации и длинного списка. Решения и их условия остаются прежними.

## Реализация

1. Взять геометрию из истории штатов, `definition.csv` и `provinces.bmp`.
   Охватить стартовые владения участников западной политики, Воркерланда и Иторы.
2. Создать обрезанную по своему контуру текстуру каждого видимого штата.
   Все кадры содержат непрозрачный силуэт для наведения.
3. Читать статус текущего владельца штата. Использовать только временные
   переменные GUI, без периодических обработчиков, мировых обходов и сохранения
   копии влияния. Перед чтением владельца сбрасывать временный кадр.
4. В подсказке участка показывать текущих владельца, контролёра и его политический
   статус. Внизу показать 11 флагов участников с подсказками, включая отсутствующих.
5. Удалить старую иллюстрацию и описание категории. Правила шкалы перенести
   в подсказку легенды; статусы стран оставить в существующем scripted localisation.
6. Проверить границы +/-20 и +/-50, приоритет стороны войны, нейтралитета и
   зависимости; владение после распада; отсутствие записи в `--check`;
   идемпотентность `--apply`; кодировки и сохранность чужих секций.

## Отображение

Золотой - Воркерланд, синий - Итора. Светлый цвет означает готовность к союзу
или уже выбранную сторону войны; приглушённый - склонность с правом прохода.
Серый означает колебание, отдельная светлая штриховка - объявленный нейтралитет,
диагональная штриховка - зависимость. Страны вне этой механики приглушены.
Подробности различий раскрывает подсказка, использующая существующий статус.

Границы следуют штатам; цвет следует их текущему владельцу, а не стартовому тегу.
Воркерланд определяется через `event_target:ADISCORD_vorkerland_nation`.
Флаги в нижней строке - стандартные флаги тегов, без косметических вариантов.

Сборщик: `tools/builders/build_adiscord_west_influence_map.py`.
По умолчанию он только проверяет выходы. Запись требует `--apply`.
Макет `docs/mockups/west_influence.html` использует условные значения влияния,
не считывает открытую игру и показывает внешний вид вместе с подсказками.

Нативную отрисовку, размеры категории и подсказки проверяет пользователь
после перезапуска игры. Computer Use и запуск игры для разработки не применяются.
