# Политическая карта столицы WRK

Карта занимает 330x290 внутри окна 460x524. Позиция карты (65, 48),
имена существующих слоёв и порядок кадров сохранены. Под картой находится
карточка выбранного района и меры; окно двора остаётся 460x360.

## Оформление и управление

План полупрозрачный: виден штатный фон категории решений. Улицы приглушённые,
границы охристые; выбранный район отмечен золотым контуром. Красный обозначает
опасность и маршрут. Геометрия девяти штатов 32-40 читается из карты мода;
уличная сеть воспроизводима благодаря фиксированному seed.

Подписи легенды скрыты; значения знаков приведены в подсказках районов.
Поверх декоративных слоёв находятся непересекающиеся кнопки районов.
Их обработчики используют нативный суффикс `_click_enabled`.
Наведение на любую точку района подсвечивает его границу. Щелчок по району
или видимой метке выбирает его. Выбор хранится только в переменной интерфейса
`WRK_capital_selected_state`; без выбора показывается центральный район 32.
Силуэт 40 включает Башню с полем 2 пикселя и вычитается из соседних силуэтов.
Пересечений областей попадания нет.

Над картой показаны три значения влияния лагерей. Полный прежний отчёт об
объектах наследства, лагерях, балансе и столице находится в "Сводке".
Статус района использует существующий `WRKGetCapitalDistrictNote`.

Карточка показывает меры соответствующего аппарата: четыре меры против
недовольства или пять операций сети. Кнопки запускают исходные targeted
решения. Цена, выплаты, сроки, отмена и последствия остаются у этих решений.
Сборщик читает их `visible`, `target_trigger`, `available` и `cost`, подставляет
конкретный штат вместо `FROM` и повторяет проверки непосредственно при клике.
Недостаток средств блокирует кнопку, но не скрывает её. Фокусные ограничения
сохраняются. Для Башни мер по дистриктам нет.

## Генерация и проверка

Владелец выходов: `tools/builders/build_adiscord_vorkerland_capital_map.py`.
В GUI/GFX, scripted GUI и локализации сборщик обновляет обозначенные секции;
в описании довоенной категории оставляет компактную строку лагерей.
Остальные секции сохраняются. PNG вручную не редактируются.

```powershell
python -B tools/builders/build_adiscord_vorkerland_capital_map.py --check
python -B tools/builders/build_adiscord_vorkerland_capital_map.py --apply
python -B tools/builders/build_adiscord_vorkerland_capital_map.py --check
python -B -m unittest tools.tests.test_build_adiscord_vorkerland_capital_map tools.tests.test_vorkerland_preparation
```

`docs/mockups/vorkerland_capital.html` - автономный интерактивный макет.
В нём можно выбрать район и посмотреть режим комитетов или сети. Числа
условные; демонстрационные кнопки не запускают игру и не воспроизводят
всю симуляцию. В игре режим определяется существующим аппаратом власти.

Статические тесты проверяют маски, кадры, подсказки, исходные условия мер,
защиту клика, отсутствие записи в режиме проверки и идемпотентность сборки.
Нативное наведение, обновление карточки и оплату решения проверяет пользователь
в игре. Computer Use и запуск игры не применяются.
