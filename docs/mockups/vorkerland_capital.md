# Политическая карта столицы WRK

## Реализация

1. Прочитать геометрию всех девяти штатов 32-40 из `history/states`,
   `map/definition.csv` и `map/provinces.bmp`. Сохранить пропорции и ориентацию.
2. Построить улицы с фиксированным seed, обрезать их масками штатов.
   Цветные кадры меняют только улицы. Границы остаются нейтральными.
3. Создать горизонтальные PNG-ленты кадров и два окна в существующих GUI/GFX.
   Сборщик владеет только своими явно обозначенными секциями этих файлов.
4. Собрать автономный HTML-макет с переключением кадров и маршрутов.
5. Проверить отсутствие записей при `--check`, геометрию и прозрачность,
   порядок слоёв и кадров, сохранность существующих окон. Выполнить
   `--check`, `--apply`, повторный `--check`, валидатор проекта и `git diff --check`.

## Визуальный контракт

- Карта: 330x290, окно: 460x360, карта слева (10, 48), легенда справа.
- Комитеты Уоркера: золотой `#EBCB64`.
- Штаб Петрищева: фиолетовый `#B39AF2`.
- Сеть Воркса: салатовый `#A9D66F`.
- Базовые улицы: светлая бирюза `#A2DAD5`; фон: графит `#20272B`.
- Красный `#F46565`: раскрытие, волнения, бунт и маршруты.
- Ячейка и патруль: нейтральные светлые знаки, без ложного сигнала опасности.
- Оспариваемые улицы: чередование трёх цветов лагерей, без заливки.
- Карточки: нейтральная серая, за штаб фиолетовая, против светлая со знаком минуса.
  Отношение "против" само по себе не приписывает фигуру другому лагерю.

Порядок кадров и имена соответствуют заданию. Первый кадр подсветки,
маршрута и метки полностью прозрачен. Слои: фон, улицы штатов, маршрут,
метки. Башня Единства обозначена отдельным силуэтом на фоне.

Управляемые штаты: 32 - Центральный, 33 - Юго-Восточный,
34 - Нефтегазовый, 35 - Старый Воркенсберг, 36 - Северный,
37 - Северо-Западный, 38 - Юго-Западный, 39 - Промышленный,
40 - Башня Единства. Для каждого существуют спрайт
`GFX_WRK_capital_state_<id>` и элементы `WRK_capital_<id>_state`,
`WRK_capital_<id>_marker`. У всех одинаковый порядок шести кадров.

## Сборка и интеграция

```powershell
python -B tools/builders/build_adiscord_vorkerland_capital_map.py --check
python -B tools/builders/build_adiscord_vorkerland_capital_map.py --apply
python -B tools/builders/build_adiscord_vorkerland_capital_map.py --check
```

Макет: `docs/mockups/vorkerland_capital.html`. Все изображения встроены;
он открывается локально без сервера. Подписи в макете демонстрационные,
не являются игровой локализацией. PNG и HTML редактируются через сборщик.

Назначение кадров, видимость окон, персонажей, имён и статусов выполняет
исполнитель механик. GUI ссылается на `WRK_capital_title`,
`WRK_capital_legend_1..3`, `WRK_intrigue_<n>_name` и
`WRK_intrigue_<n>_status`. Новых записей локализации сборщик не создаёт.
Легенда использует кадры 3 (раскрыта), 4 (волнения), 5 (бунт).
Портреты имеют исходный размер 156x210 и GUI scale 0.28; до назначения
персонажей показан нейтральный силуэт. Карточки 220x100, две колонки,
три ряда. Оба окна требуют подключения внешним scripted GUI.
Исполнителю механик необходимо подключить все девять штатов, включая
34, 35 и 39. Макет позволяет отдельно переключать влияние и метку
каждого штата. Расширение охвата не меняет размеры окон или имена
существующих элементов.

Статическая проверка не подтверждает отрисовку движком. Заказчик проверяет
в игре наложение слоёв, локализованные подписи и смену кадров после
подключения механик. Computer Use и запуск игры сборщику не нужны.
