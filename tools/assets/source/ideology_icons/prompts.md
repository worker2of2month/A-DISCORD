# Ideology emblems

Generated with the built-in imagegen tool. Masters retain the original alpha.
Runtime textures and the size comparison are owned by
`python -B -m tools.builders.build_adiscord_ideology_icons`.
Use `--check` before `--apply`, then repeat `--check` to verify the export.
To export one emblem and preview the other installed textures, add
`--only dorian_technocracy` (or another asset ID listed below).

A broad industrial cogwheel forms the circular outer border, brushed silver steel with restrained brass fasteners. The book pages have only a few abstract fine ruled lines, absolutely no letters, words, numbers or pseudotext. Distinct clear silhouettes legible at 125x125 and 70x70. Front-facing centered symmetrical heraldic game UI badge, lightly worn beveled metal, painted realistic material, crisp high contrast, restrained ornament, no excessive glow. Fill 88 percent of a square 1:1 canvas. Fully transparent background outside the emblem. No crown, no eye, no sword, no atom or atomic orbits, no skull, no watermark, no multiple icon sheet.
