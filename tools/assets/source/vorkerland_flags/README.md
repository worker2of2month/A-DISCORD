# RUS imperial flags

The original PNG artwork is preserved by `tools.builders.build_adiscord_vorkerland_original_flags`. The builder exports opaque RGBA TGA textures at 82x52, 41x26 and 10x7.

`RUS_restoration_state` is selected when the scientists outweigh the compromise range at proclamation. `RUS_black_banner_empire` is selected for the Black Army. The balanced result keeps `RUS_last_empire` and its existing flag. Selection is owned by `ADISCORD_vorkerland_rus_proclaim_last_empire` in `common/scripted_effects/ADISCORD_vorkerland_effects.txt`.

Check with `python -B -m tools.builders.build_adiscord_vorkerland_original_flags --tags RUS_restoration_state RUS_black_banner_empire --check`; export with the same command using `--apply`.

Scientific reconstruction under an imperial Khan, dignified and austere.
