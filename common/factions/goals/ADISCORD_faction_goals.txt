# in every duration slot: an entirely empty selectable-goal pool makes the
# HOI4 1.19 faction AI enqueue a set-goal command with an invalid database
# pointer. Locked research and military tab tooltips resolve
# FACTION_ACCESS_TO_RESEARCH_TAB / FACTION_ACCESS_TO_MILITARY_TAB by looking up
# the vanilla unlock-goal tokens. Those definitions must stay in the database
# even when the assigned A-Discord goals already carry the same unlock
# effects for serialized saves.
